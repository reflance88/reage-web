## 쿠폰 만들기 (image 1)
### 발급 정보 섹션
- 쿠폰이름 [필수] - 텍스트 입력
- 쿠폰설명 - 텍스트 입력
- 혜택구분 [필수] - 드롭다운 (할인금액/할인율/적립금액/적립율/기본배송비할인/전체배송비할인/즉시적립) + 값 입력 + KRW
- 발급구분 - 드롭다운 (대상자 지정 발급/조건부 자동/고객 다운로드/정기 자동) + 대상 드롭다운 (전체 회원 대상)
- 노출시점 - 라디오 (즉시 노출 / 지정한 시점에 노출)

### 사용 정보 섹션
- 사용 기간 - 드롭다운 (기간 설정/발급일로부터) + 날짜 범위 + 빠른 선택 버튼 (오늘/3일/7일/1개월/기본 사용기간 설정)
- 사용 범위 [필수] - 체크박스 (PC쇼핑몰 / 모바일쇼핑몰)
- 적용 범위 - 드롭다운 (주문서 쿠폰 / 상품 쿠폰)
- 쿠폰적용 상품 선택 - 라디오 (전체상품 / 특정상품 / 제외상품)
- 쿠폰적용 분류 선택 - 드롭다운 (모두 적용)
- 사용가능 기준금액 - 드롭다운 (제한 없음 / 주문금액 기준 / 상품금액 기준)
- 적용 계산 기준 - 드롭다운 (할인(쿠폰 제외) 적용 전 결제 금액 / 할인 적용 후)
- 동일쿠폰사용 설정 [필수] - 주문서당 N개 까지 사용가능
- 사용가능 결제수단 [필수] - 라디오 (제한없음 / 결제수단 선택)

### 개별 이미지 설정 섹션
- 개별 이미지 설정 - 라디오 (기본 이미지 사용 / 직접 업로드)

### 부가 서비스 섹션
- 로그인시 쿠폰발급 알림 - 라디오 (사용함 / 사용안함)
- 쿠폰발급 SMS 발송 - 라디오 (발송함 / 발송안함)
- 쿠폰발급 이메일 발송 - 라디오 (발송함 / 발송안함)

## 할인코드 등록 (image 3)
### 기본 정보
- 할인코드 이름 [필수]
- 입력코드 [필수] + 확인 버튼
- 혜택구분 [필수] - % / 절사단위 (드롭다운) / 상품당 최대 할인금액 (입력) KRW

### 사용 정보
- 사용기간 - 날짜 범위 + 빠른 선택 (오늘/3일/7일/1개월/3개월/1년)
- 적용범위 - 라디오 (전체 상품 / 특정 상품 / 특정 분류)

### 제한 정보
- 사용가능 최소 주문금액 - 라디오 (제한안함 / 제한함)
- 최대사용 가능횟수 - 라디오 (제한안함 / 제한함)
- 사용가능 대상 - 라디오 (제한안함 / 회원만)
- 동일인 사용 가능횟수 - 라디오 (제한안함 / 제한함)
- 저장 버튼

## 리마인드 알림 등록 (image 5)
### 알림 유형 선택 (8개 카드)
- 최근 조회한 상품을 보여주고 구매를 유도
- 상품을 구매한 회원에게 다른 상품을 추천
- 장바구니에 담긴 상품을 보여주고 구매를 유도
- 관심상품에 담긴 상품을 보여주고 구매를 유도
- 적립금 보유중임을 알려주고 구매를 유도
- 쿠폰 보유중임을 알려주고 구매를 유도
- 로그인한 지 오래된 회원에게 로그인을 유도
- 휴면예정임을 알려주고 로그인을 유도

### 기본 설정
- 사용여부 - 라디오 (사용함 / 사용안함)
- 알림명 [필수] - 텍스트 (0/50)

### 알림 유형 및 조건
- 알림 유형 - 드롭다운 (기본 알림)

### 수신 대상 설정
- 수신 대상 - 드롭다운 (휴면 전환 예정) + N일 전 회원 대상으로 발송함
- 수신 대상 발송제외 - 회원등급별 발송여부 (발송함/발송안함 선택 박스)
- 수신거부회원 발송여부 - 라디오 (발송함 / 발송안함)
- 특별관리회원 발송여부 - 라디오 (발송함 / 발송안함)
- 불량회원 발송여부 - 라디오 (발송함 / 발송안함)
