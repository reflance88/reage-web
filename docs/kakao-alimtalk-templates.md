# REAGE 카카오 알림톡 템플릿 초안

> 아래 8개 템플릿은 카카오 비즈니스 채널 심사 등록용 초안입니다.
> 알리고(또는 솔라피) 관리자 페이지에서 채널 연결 후 아래 내용을 그대로 붙여넣어 심사 신청하시면 됩니다.
> `#{변수명}` 형식은 발송 시 실제 값으로 치환되는 변수입니다.

---

## 템플릿 1 — 신규 주문 (결제 완료)

**템플릿 코드:** `ORDER_COMPLETE`
**발송 시점:** 고객이 결제를 완료했을 때

```
#{고객명}님, 주문이 완료되었어요.

- 주문일 : #{주문일}
- 주문번호 : #{주문번호}
- 상품명 : #{상품명}
- 주문금액 : #{주문금액}원

영업일 기준 1~2일 내 배송이 시작됩니다.
문의: 010-9679-9498
```

**버튼:** `주문 확인` → `#{주문확인URL}`

---

## 템플릿 2 — 입금 안내 (무통장 입금)

**템플릿 코드:** `BANK_TRANSFER_GUIDE`
**발송 시점:** 무통장 입금 주문 생성 시

```
#{고객명}님, 입금 안내 드려요.

- 주문번호 : #{주문번호}
- 상품명 : #{상품명}
- 입금은행 : #{입금은행}
- 입금계좌 : #{입금계좌}
- 예금주 : #{예금주}
- 금액 : #{주문금액}원

입금 확인 후 배송이 시작됩니다.
```

**버튼:** `주문 확인` → `#{주문확인URL}`

---

## 템플릿 3 — 배송 안내 (배송 준비 완료)

**템플릿 코드:** `SHIPPING_READY`
**발송 시점:** 관리자가 주문 상태를 '배송준비중'으로 변경 시

```
#{고객명}님, 주문하신 상품을 발송했어요.

- 상품명 : #{상품명}
- 주문번호 : #{주문번호}

배송 시작 시 송장번호를 별도 안내해 드립니다.
문의: 010-9679-9498
```

**버튼:** `주문 확인` → `#{주문확인URL}`

---

## 템플릿 4 — 배송 시작 (운송장 등록)

**템플릿 코드:** `SHIPPING_STARTED`
**발송 시점:** 관리자가 운송장 번호를 등록했을 때

```
#{고객명}님, 주문하신 상품이 배송 중이에요.

- 상품명 : #{상품명}
- 주문번호 : #{주문번호}
- 택배사 : #{택배사}
- 송장번호 : #{송장번호}

택배사 홈페이지에서 배송 현황을 확인하실 수 있습니다.
```

## 템플릿 5 — 배송 완료

**템플릿 코드:** `DELIVERY_COMPLETE`
**발송 시점:** 관리자가 주문 상태를 '배송완료'로 변경 시

```
#{고객명}님, 상품 배송이 완료되었어요.

- 상품명 : #{상품명}

REAGE를 이용해 주셔서 감사합니다.
```

**버튼:** `쇼핑몰 바로 가기` → `https://reageweb-aerfeijb.manus.space`

## 템플릿 6 — 취소/반품/교환 완료

**템플릿 코드:** `ORDER_CANCELLED`
**발송 시점:** 주문 취소 처리 완료 시 (관리자 또는 고객 취소 모두 해당)

```

- 주문번호 : #{주문번호}
- 상품명 : #{상품명}

환불은 결제 수단에 따라 영업일 기준 3~5일 소요될 수 있습니다.
문의: 010-9679-9498
```

**버튼:** `자세히 보기` → `#{주문확인URL}`

## 등록 절차 요약

1. [카카오 비즈니스](https://business.kakao.com) 로그인 → 채널 관리자 센터 → 알림톡 채널 연결
2. [알리고](https://smartsms.aligo.in) 로그인 → 카카오 알림톡 → 채널 연동 → 템플릿 등록
3. 위 8개 템플릿을 각각 등록 후 심사 신청 (보통 1~3 영업일 소요)
4. 심사 완료 후 각 템플릿 코드(`ORDER_COMPLETE` 등)를 알려주시면 코드에 즉시 반영합니다

## 필요한 API 정보 (심사 완료 후 등록)

| 환경변수 | 설명 |
|---|---|
| `ALIGO_API_KEY` | 알리고 API 키 |
| `ALIGO_USER_ID` | 알리고 사용자 ID |
| `ALIGO_SENDER` | 발신번호 (카카오채널 등록 번호) |
| `ALIGO_KAKAO_SENDER_KEY` | 알리고 카카오 발신 프로필 키 |
| `ADMIN_PHONE` | 관리자 수신 전화번호 |
