구글 시트 연동 — 4단계 설정 가이드

원장님(고객)은 아무것도 할 필요 없습니다. 설정은 딱 한 번만 하면 됩니다.

1

Apps Script 코드 작성

AI가 구글 시트에 데이터를 저장하는 코드를 작성합니다.

AI가 합니다
2

구글 시트에 붙여넣기

구글 시트 → 확장 프로그램 → Apps Script → 코드 붙여넣기

원장님이 합니다
3

배포 버튼 클릭

구글이 전용 URL을 발급합니다. 이 URL이 "데이터 수신 주소"입니다.

구글이 합니다
4

URL 전달 → 연결 완료

발급된 URL을 AI에게 전달하면 홈페이지 폼에 연결 완료.

원장님이 합니다
⏱ 예상 소요 시간: 약 5~10분 — 코드 붙여넣기 + 배포 버튼 클릭 2단계만 직접 하시면 됩니다.
